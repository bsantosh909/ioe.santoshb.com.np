## Syllabus

1. **Airframe Structure** (4 hours)
   1. Aircraft fuselage: structure and function
   2. Aircraft wing: structure and function
   3. Aircraft tail: structure and function
   4. Landing gear: structure and function
2. **Ice and Rain Protection System** (4 hours)
   1. De-icing system
   2. Anti-icing system
   3. Rain eliminating system
   4. Ground de-icing system
   5. Drain heaters
3. **Hydraulic and Pneumatic Power System** (6 hours)
   1. Aircraft hydraulic system
   2. Hydraulic fluid types and filters
   3. Reservoir
   4. Pressure regulation
   5. Selector valves
   6. Actuating cylinder
   7. Aircraft pneumatic system
   8. Pneumatic system components
4. **Landing Gear Systems** (4 hours)
   1. General structure
   2. Steering system
   3. Brake system
   4. Aircraft landing wheels
   5. Anti-skid system
   6. Emergency extension system
   7. Auto brake system
5. **Fire Protection System** (4 hours)
   1. Types of fires and fire zones
   2. Fire detection system
   3. Extinguishing agent characteristics and system
   4. Fixed fire extinguishing system
   5. Turbojet fire protection system
   6. Lavatory fire protection system
   7. Fire prevention and protection
   8. Smoke detection system
   9. Cockpit and cabin interior
6. **Fuel System** (6 hours)
   1. System layout
   2. Fuel tanks
   3. Supply system
   4. Dumping, venting and draining
   5. Longitudinal balance fuel systems
   6. Cross feed and transfer
7. **Air Conditioning and Cabin Pressurization System** (4 hours)
   1. Air supply
   2. Air conditioning
   3. Pressurization
8. **Water and Waste System** (2 hours)
   1. Water system
   2. Toilet system
   3. Corrosion aspect
9. **Aircraft Electrical System** (4 hours)
   1. Aircraft battery
   2. AC/DC/emergency power generation
   3. Voltage regulation
   4. Power distribution
   5. Circuit protection
   6. External/ground power
   7. Aircraft lighting system
10. **On Board Systems** (4 hours)
    1. Central maintenance computers
    2. Data loading system
    3. Electronic library system
11. **Equipment and Furnishing** (2 hours)
    1. Equipment layout
    2. Cabin furnishing installation
    3. Cabin entertainment equipment
    4. Galley installation
    5. Cargo handling and retention equipment; airstairs

## Practicals

1. Aircraft observation and presentation: students participate in an aircraft or airline facility to observe various aircraft systems, including flight control, hydraulic, electrical and avionics systems, along with fuel systems, environmental control systems and basic maintenance practices, then prepare and deliver a presentation based on their observations.
