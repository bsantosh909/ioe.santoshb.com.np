## Syllabus

1. **Introduction** (5 hours)
   1. Definition of project and project management
   2. Project objectives
   3. Classification of projects
   4. Advantages of project management
   5. Project management context as per Project Management Institute (PMI)
   6. ICT product life cycle and its characteristics
   7. Overview of system development methodologies
2. **Project Management Body of Knowledge** (6 hours)
   1. Project environment
   2. Managerial skills: conceptual, technical, human-relation
   3. Role and responsibilities of key project members
   4. Problem solving using problem trees
   5. Project and organizational structure: system view of project management, functional organization, projectized organization, matrix organization, organizational structure influences on projects
3. **Portfolio and Project Management Framework** (2 hours)
   1. PMI framework
   2. Program management
   3. Portfolio management
   4. Project management office
   5. Drivers of project success
   6. Inhibitors of project success
4. **Project Management Process Groups** (2 hours)
   1. Project management processes
   2. Overlaps of process groups in a phase
   3. Mapping of project management process groups to area of knowledge
5. **Project Integration Management** (2 hours)
   1. Develop project charter
   2. Develop project management plan
   3. Direct and manage project execution
   4. Monitor and control project work
   5. Integrated change control
   6. Close project or phase
6. **Project Scope Management** (2 hours)
   1. Develop preliminary project scope statement
   2. Create work breakdown structure
   3. Scope verification
   4. Scope control
7. **Project Time Management** (6 hours)
   1. Activity definition, decomposition of activities, activity attributes
   2. Activity sequencing, precedence relationship, network diagram, precedence diagram method, arrow diagramming method
   3. Activity resource estimating, determining resource requirements
   4. Schedule development and control, principles of scheduling, milestones, forward pass, backward pass, critical path method (CPM), critical chain technique, Gantt chart, schedule control
8. **Project Cost Management** (5 hours)
   1. Cost and project cost management
   2. Cost estimates: types, process and accuracy; enterprise environmental factors, organizational process assets, cost estimating tools
   3. Cost budgeting, cost aggregation, deriving budget from activity cost
   4. Cost control process, cost control methods
   5. Earned value management, EVM benefits, variance analysis
9. **Project Quality Management** (2 hours)
   1. Quality theories
   2. Quality planning and requirements, cost of quality, quality management plan
   3. Quality assurance, quality audit, approach to a quality audit
   4. Quality control process, control chart, Pareto charts
   5. Testing of IT system, the test life cycle
10. **Project Communication Management** (2 hours)
    1. Importance of communication management
    2. Communications planning process, communication requirement analysis, organizing and conducting effective meeting
    3. Information distribution process
    4. Performance reporting process, integrated reporting system
11. **Project Risk Management** (3 hours)
    1. Understanding project risks
    2. Risk management plan and planning process
    3. Risk identification techniques
    4. Qualitative risk analysis process
    5. Quantitative risk analysis process, modeling techniques
    6. Risk response planning, resolution of risk, strategies for negative and positive risks
    7. Risk monitoring and control process
12. **Project Procurement Management** (3 hours)
    1. Procurement management process flow
    2. Plan purchases and acquisition process, enterprise environmental factor, organizational process assets
    3. Plan contracting process, standard forms, evaluation criteria
    4. Request seller response process; select seller process
    5. Contract administration process
    6. Contract closure process
13. **Project Resource and Stakeholder Management** (3 hours)
    1. Developing the resource management plan and team charter
    2. Estimating activity resources
    3. Acquiring resources
    4. Developing the project team
    5. Managing the project team
    6. Monitoring and controlling resources
    7. Identifying stakeholders
    8. Planning, managing and monitoring stakeholder engagement
14. **Trends in ICT Project Management** (2 hours)
    1. Agile project management
    2. Balanced scorecard and ICT project management
    3. Project management maturity models
    4. Certification process flow
    5. Code of ethics
    6. Future trends
