## Syllabus

1. **Overview of GIS and GIS Software** (2 hours)
   1. Basic concept of GIS
   2. GIS functionalities
   3. Components of GIS
   4. Application and Integration of GIS in different disciplines
   5. Historical developments of GIS
   6. GIS software
2. **Coordinate Systems and Map Projections** (3 hours)
   1. Fundamentals of coordinate systems
   2. Geographical and projected coordinate systems
   3. Coordinate transformations and map projections
   4. Commonly used map projections
   5. Georeferencing and spatial adjustment
3. **Spatial Data Models** (4 hours)
   1. Vector data model: Point, line and polygon; Spaghetti data model, topological data model
   2. Raster data model: Raster data structure; Discrete vs continuous data; Thematic, imagery and spectral; Data compression
   3. Comparison between vector and raster data
   4. TIN data model - Delaunay triangles
   5. Data conversion - Rasterization and vectorization
4. **Database Concepts** (5 hours)
   1. Database and database management system
   2. Database components
   3. Types of database models: Flat files, hierarchical database, network database; Relational database; Object-oriented and object-relational database
   4. Normalization: Relational database
   5. Standard query language (SQL)
   6. Metadata - data about data
5. **Data Sources and Acquisition** (5 hours)
   1. Primary and secondary data sources
   2. Acquiring spatial data (Vector and raster)
   3. Acquiring attribute data
   4. External sources
   5. Ground surveying
   6. Digitization, digitization process and errors
   7. GIS data formats and issues of data interoperability
   8. Data standards (OGC and open data standards, ISO Standards)
   9. Data quality and data accuracy (Positional accuracy, attribute accuracy, logical consistency and completeness)
   10. Sources of errors and managing errors in GIS
6. **Spatial Data Analysis** (12 hours)
   1. Spatial analysis
   2. Spatial join and spatial relate
   3. Vector overlay operations (Point-in-polygon, line-in-polygon and polygon-in-polygon)
   4. Raster Analysis (Single layer analysis-classification and reclassification, multiple layer analysis, raster overlay)
   5. Measuring distance and length (Euclidean distance, Manhattan distance)
   6. Measuring area and perimeter
   7. Proximity analysis (Vector and raster buffer)
   8. Pattern analysis (Cluster detection, measure of density and dispersion, seek computation)
   9. Spatial Interpolation (Thiessen polygon, nearest neighbor (NN), inverse distance weighting (IDW), spline, kriging)
   10. Map calculations (Raster calculator, zonal Statistics)
   11. Network analysis (Geocoding, types of networks - undirected and directed networks, linear referencing)
7. **Terrain Modeling** (3 hours)
   1. Digital elevation model (DEM)
   2. Slope and aspect
   3. Viewshed and hillshade
   4. Contours, longitudinal profile and cross-sections, plan and profile curvatures
8. **Watershed Analysis** (5 hours)
   1. Flow direction and flow accumulation
   2. River network
   3. Basin/watershed
   4. Morphological parameters
9. **Cartography and Map Making** (6 hours)
   1. Gentle introduction to cartography
   2. Early development of mapping
   3. GIS and modern map making
   4. Cartographic process
   5. Types of maps: Reference and thematic
   6. Elements of map
   7. Principles of map design
   8. Map output formats

## Practicals

1. Familiarization with software and hardware and data
2. Spatial database development using field survey data
3. Linking non-spatial and spatial database - census data
4. Map projection based on modified UTM
5. Spatial data query - query by attributes, query by location
6. Vector and raster overlay
7. Surface analysis
8. Hydrological Analysis
9. Map layout (map elements, scale and print layout)
10. Mini-project on GIS application or customization
