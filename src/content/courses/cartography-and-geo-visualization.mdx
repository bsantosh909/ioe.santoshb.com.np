## Syllabus

1. **Fundamentals of Cartography** (3 hours)
   1. History of cartography
   2. Scope of cartography
   3. Principle of cartography
   4. Cartographic information system
2. **Maps** (3 hours)
   1. Maps and their types
   2. Components of map
   3. Map as an interface to data
   4. The map design process
   5. Basic steps for communicating map information
3. **Generalization** (5 hours)
   1. Principles and objective of generalization
   2. Techniques and methods of generalization
   3. Algorithms and tools for generalization
   4. Generalization in different types of maps
   5. Challenges and solutions in generalization
4. **Colour Theory and Graphic Variable** (5 hours)
   1. Nature of light
   2. Additive and subtractive colours
   3. Colour triangle
   4. Choice of colours (Colour charts)
   5. Importance of graphic variables
   6. Concept of visual perception
   7. Types of graphic variables
5. **Typography** (4 hours)
   1. Characteristics and types typography
   2. General typographic guidelines
   3. Specific typographic guidelines
   4. Automated type placement
6. **Elements of Map Projections** (5 hours)
   1. Concepts of map projection
   2. The reference globe and developable surfaces
   3. The mathematics of map projections
   4. Map projection characteristics (Class, case aspect)
   5. Distortion on map projections
   6. Projection properties
7. **Data Classification** (5 hours)
   1. Data measurement level
   2. Different classification methods
   3. Criteria for selecting a classification method considering the spatial distribution of the data
8. **Mapping Techniques** (6 hours)
   1. Aesthetic and design
   2. Relief representation
   3. Topographic data representation
   4. Geographical names
   5. Common thematic maps (Cartograms, chorochromatic maps, dot maps, proportional point symbol maps, flowline maps, isoline maps, cartograms, prism maps, choropleth map)
9. **Map Reproduction Techniques** (5 hours)
   1. Planning, map editing, and raster image processing for print production
   2. Screening for point reproduction
   3. Halftone and stochastic screening
   4. Aspects of color, printing-process color, spot color, high-fidelity process color, continuous tone color printing
   5. Color management system, high volume prints reproduction-pre-phase, file formats, proofing methods
   6. Offset lithographic printing, computer-to-plate, direct-to-plate
10. **Geo-visual Exploration and User Usability** (4 hours)
    1. Visualization and maps, geo-visualization
    2. Brushing-attribute, geographical, temporal, exploratory tools, visual analytics
    3. User centered design of geo data dissemination systems
    4. Use contexts, user data collection and analysis methods

## Practicals

1. Map reading and interpretation techniques
2. Cartographic design and layout principles
3. Map projections and coordinate systems
4. Color theory in cartography: Enhancing map readability
5. Typography in cartography: Labeling techniques and best practices
6. Generalization techniques for simplifying spatial data
7. Symbolization and map symbols: Effective use in cartography
8. Designing choropleth maps for demographic data
9. Proportional symbol mapping: Visualizing quantitative data
10. Creating and analyzing thematic maps
11. Multivariate mapping and data visualization
12. Creating story maps and narrative cartography
