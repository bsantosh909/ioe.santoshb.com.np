## Syllabus

1. **Introduction** (2 hours)
   1. AutoCAD interface
   2. Coordinate system icons, world coordinate system, user coordinate system
   3. Drawing units and scaling, drawing limits and MV setup
   4. Utility commands: help, end, quit, qsave, save as, save, savetime
2. **Drawing Aids and Commands** (4 hours)
   1. Draw lines, polylines, rectangles, polygon, constructed lines, rays
   2. Curves, circles, arcs, ellipse, elliptical arcs, donuts and points
   3. Drawing aids: isometric, snap, grid, ortho, object snap, polar tracking, dynamic input, ISO plane
   4. Function keys
3. **Drawing Modification Tools and Commands** (4 hours)
   1. Move, copy, rotate, scale, mirror, stretch, array, explode, erase
   2. Break, trim, extend, fillet, chamfer, offset, lengthen, join
   3. Editing: polyline, pedit, spline
   4. Undoing: redo, undo, oops, redraw
   5. Inquiry command list: dblist, id point, distance, area, volume
4. **Layer, Annotation and Hatching** (8 hours)
   1. Layers management: properties, line type, ltscale, lineweight, color, isolate, unisolate
   2. Text and entity properties
   3. Dimension types, components and dimension style manager
   4. Hatching: boundaries, hatch pattern, hatch style and alignment
5. **Display Controls and Blocks, Attributes and External References** (2 hours)
   1. Zoom, pan, managing multiple viewports
   2. Redraw, regen, regenall
   3. Creating and inserting a block, block editor and xref editing
6. **Layout, Plotting, Printing and Publishing** (2 hours)
   1. Changing pen and line type parameters
   2. Changing plot model specifications and saving them
   3. Layout and page set up manager
   4. Plotting and publishing to PDF
7. **Basic Three-Dimensional Model of Solids** (4 hours)
   1. Types of 3D models and three-dimensional coordinate system
   2. Three-dimensional modelling: box, cone, cylinder, sphere, wedges, pyramid
   3. Solid editing: extrude, union, subtract, intersect solids
   4. Solid modify: rotate 3D, mirror 3D, 3D array, 3D align, fillet, chamfer, slice, section
   5. Mesh, visualize, rendering
8. **Basic 3D Modelling of Building** (4 hours)
   1. Introduction to Google SketchUp interface
   2. Draw tools, modifying tools, editing tools
   3. Camera: orbit, zoom, pan
   4. Window: entity info, materials, styles, scenes
   5. Export, print, animation, model info

## Practicals

Thirty hours: drafting of a building (plan, elevation, section, wall section), municipal drawings preparation, and 3D model of a building.
