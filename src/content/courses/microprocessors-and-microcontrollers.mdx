## Syllabus

1. **Introduction** (5 hours)
   1. Introduction and history of microprocessor
   2. Microprocessor based system
   3. Bus organization of a microprocessor
   4. Stored program concept (SPC) and Von Neumann architecture, Harvard architecture
   5. Control Unit: definition, types, block diagram and comparison
2. **The 8085 Microprocessor** (10 hours)
   1. Features of 8085
   2. Pin description and internal architecture
   3. Instruction and data formats
   4. Addressing modes and instruction set
   5. Assembly programming examples: basic data transfer operations; basic arithmetic and logical operations; conditions and loops; array and table processing; 8-bit and 16-bit multiplication and division operations; data conversion (bcd to binary, binary to bcd)
   6. Interrupts: interrupt pins, interrupt priorities, types of interrupts, interrupt instruction, processing sequence of interrupt
3. **The 8086 Microprocessor** (10 hours)
   1. Features of 8086
   2. Internal architecture and pipelining
   3. Addressing modes and instruction set
   4. Assembly language syntax: comments, identifiers, reserve words, operators, statement, directives
   5. Assembling, linking and execution
   6. DOS function / keyboard and video services: int 10h, int 21h
   7. Assembly programming examples: data transfer, arithmetic and logical operations; conditions and loops; array and string processing; 8-bit and 16-bit multiplication and division; use of input and output devices; data conversion
   8. Interrupt: interrupt pins, priorities, instructions, types, ivt and its organization
4. **Microprocessor System** (10 hours)
   1. Memory: classification, hierarchy
   2. Address decoding and mapping i/o: definition, types
   3. Address decoding for I/O ports (NAND Gate and Decoder) and memory (RAM, ROM) for 8085
   4. Interfacing: definition, needs, types, comparison
   5. Serial Interface: synchronous and asynchronous transmission, RS 232
   6. Parallel Interface: simple, strobe, single and double handshaking
   7. PPI Device 8255: block diagram, modes of operations and control words generations
   8. DMA and DMA controller
   9. Bus timing diagram and rtl (register transfer language) for various instructions in 8085
5. **The 8051 Microcontroller** (10 hours)
   1. Microcontroller survey: 4-bit, 8-bit, 16-bit and 32-bit microcontrollers
   2. Introduction to 8051 microcontroller and its family
   3. Pin description, internal architecture and programming model
   4. Internal memory organization and SFR (Special Function Registers)
   5. The timer control (TMOD) and special function registers
   6. The timer mode control (TCON) and special function registers
   7. Timer modes of operations (Mode 1, Mode 2, Mode 3)
   8. Addressing modes and instruction set
   9. Programming examples in assembly and c: basic data transfer, arithmetic and logic operations; multiplication and division; conditions and loops; array processing and look up table; use of timers for delay and pulse generations; interfacing with seven segment display and liquid crystal display

## Practicals

1. Familiarization with data transfer instructions in 8085
2. Familiarization with arithmetic instructions in 8085
3. Familiarization with logical instructions in 8085
4. Familiarization with branching and stack operations in 8085
5. Familiarization with miscellaneous problems in 8085
6. Familiarization with assembly language programming in 8086
7. Familiarization with dos service int 21h in assembly language programming in 8086
8. Familiarization with bios service int 10h in assembly language programming in 8086
9. Solving miscellaneous problems with assembly language programming in 8086
10. Familiarization with data transfer, arithmetic and logical instruction in 8051
11. Familiarization with branching and bit manipulation operations in 8051
12. Familiarization with timers for delay and wave pulse generation in 8051
