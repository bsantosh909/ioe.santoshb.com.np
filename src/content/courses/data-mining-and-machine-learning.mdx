## Syllabus

1. **Introduction** (6 hours)
   1. Overview of data mining and machine learning
   2. Data mining views: Data, application, knowledge and technique
   3. Data mining: Major issues, ethics, resources
   4. Importance and applications in geospatial domain
2. **Data Preprocessing and Cleaning** (8 hours)
   1. Data quality and missing data
   2. Data integration and transformation
   3. Data reduction techniques
   4. Data warehouse: Architecture, Data Cube and OLAP
3. **Exploratory Data Analysis** (8 hours)
   1. Descriptive statistics
   2. Data segregation and classification
   3. Geospatial data visualization
4. **Supervised Classification Techniques** (10 hours)
   1. Decision trees
   2. Bayesian classification
   3. k-Nearest Neighbors (k-NN)
   4. Support vector machines (SVM)
   5. Random forest (RF)
   6. Geospatial classification applications
5. **Unsupervised Classification Techniques** (10 hours)
   1. Introduction to clustering
   2. k-Means clustering
   3. Hierarchical clustering and grid based clustering
   4. Density-based spatial clustering of applications with noise (DBSCAN)
   5. Applications of clustering in geospatial domain
6. **Association Rule Mining** (10 hours)
   1. Basic concepts of frequent, closed and max-patterns, and association rules
   2. Introduction to Apriori Algorithm
   3. FP-Growth Algorithm
   4. Spatial association rules
   5. Spatial co-location pattern
   6. Mining Semantics-rich movement patterns and periodic movement patterns
7. **Geospatial Applications and Case Studies** (8 hours)
   1. Case studies in land use and land cover classification
   2. Predictive modeling in disaster management
   3. Spatial data mining for urban planning
   4. Integrating GIS and machine learning for geospatial solutions

## Practicals

1. Geospatial data collection from different sources, cleaning and preparation using python and GIS tools
2. Visualization of geospatial data using GIS software and exploratory data analysis with python libraries
3. Implementation of classification algorithms on geospatial data
4. Clustering geospatial data, geospatial data for market basket analysis and finding spatial pattern using geospatial data
5. Developing and training neural networks for geospatial applications
6. Implementing time series analysis for geospatial data
