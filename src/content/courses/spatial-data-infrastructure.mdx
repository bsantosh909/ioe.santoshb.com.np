## Syllabus

1. **Introduction** (6 hours)
   1. Definition and components
   2. Importance and benefits
   3. History and evolution
   4. SDI frameworks and models (Global, regional, national, local)
   5. Geospatial data formats
   6. Distributed geospatial databases
2. **Data Quality and Standards** (8 hours)
   1. Data quality and standards
   2. International organization of standardization (ISO TC 211, TC 204, JTC-1)
   3. World wide web consortium (W3C), Open geospatial consortium (OGC)
   4. Data exchange formats and interoperability
   5. National standards organizations, distributed computing with web services
   6. OGC web service, architecture
   7. SDI architectures based on open source software
3. **Meta-data Principles** (8 hours)
   1. Levels of metadata
   2. Linkage between geospatial data and metadata
   3. Metadata standards
   4. Implementation approach
   5. Implementation issues
   6. Gazetteers and thesauri
4. **Geospatial Data Catalogue** (6 hours)
   1. Catalogue server, service development design
   2. Software implementations
   3. Catalogue gateway and access interface development
5. **SDI Guiding Principles** (6 hours)
   1. Data stewardship, data security
   2. Data accessibility, data interoperability
   3. Data reusability, data synchronization
   4. Data usability
6. **Open GIS and Web Mapping** (8 hours)
   1. Map servers and software
   2. Geoportals overview
   3. Geoportal service requirement: Portrayal services, data services
   4. Catalogue services data access and delivery: Open access to data
7. **Policy and Organizational Structure** (8 hours)
   1. Organizational approach, implementation approach
   2. Institutional arrangements (Policies, standards) and organizational changes
   3. Global SDI: GSDI association, UN/GGIM
   4. Regional SDI: INSPIRE, ASEANSDI
   5. National SDI: Present situation and challenges
8. **Applications and Future Trends** (10 hours)
   1. Applications: Environmental monitoring and management; Urban planning and land administration; Disaster management and emergency response; Transportation and infrastructure management; Natural resource management
   2. Emerging technologies: IoT, AI, and machine learning in geospatial context
   3. Trends in data sharing and open data initiatives
   4. Advances in real-time data integration and processing
   5. The role of SDI in smart cities and sustainable development

## Practicals

1. Setting up geospatial web services
2. Configuring and deploying services: Web map service (WMS), web feature service (WFS)
3. Creating and managing metadata
4. Visualizing and analyzing spatial data
5. Registering catalogue server demonstration of geo-network
6. Implementing a real-world SDI project
7. Developing a mini SDI project or case study
